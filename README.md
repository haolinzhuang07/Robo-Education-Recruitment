# Robo-Education-Recruitment

机器人协会教学部纳新任务作品仓库。本仓库以“差速移动机器人运动学入门”为主题，整理面向初学者的内训方案、授课型幻灯片和 Python 示例。

课程围绕左右轮速度与底盘运动之间的关系展开，通过几何推导、数值计算和代码实现，帮助学习者理解正运动学、逆运动学和位姿更新。

## 主要教学内容

1. 认识轮半径、轮距、车轮角速度和底盘位姿，统一单位与正方向。
2. 根据左右轮的圆弧运动关系推导轮缘线速度。
3. 通过速度的和与差推导正运动学，并反解得到逆运动学。
4. 将车体速度投影到世界坐标系，使用显式欧拉法更新位姿。
5. 用数值例题和 Python 函数核对计算结果，理解时间步长对积分误差的影响。

模型假设小车在平坦地面上运动，左右轮半径相同，车轮纯滚动且无明显侧滑。示例中的角速度表示车轮角速度，单位为 rad/s。

## 运行 Python 示例

示例只使用 Python 3 标准库。在仓库根目录执行：

```bash
python examples/diff_drive.py
```

程序会输出正运动学结果、逆运动学反算结果，以及从初始位姿出发运动两秒后的估计位姿。它还给出恒定速度下的圆弧解析解，便于与欧拉积分结果比较。

如需保存轨迹：

```bash
python examples/diff_drive.py --csv trajectory.csv
```

输出的 CSV 包含时间、位置和朝向角，可用于后续绘图或分析。

## 多人共同维护的设想

- 按用途组织文件。内训方案放在 `topic/`，课件与授课说明放在 `slides/`，示例代码放在 `examples/`。以后有独立图片资源时再增加 `assets/`。
- 每次修改前先同步主分支，在独立分支中完成一项明确的任务，例如修订公式推导或补充课堂练习。
- 提交时说明修改目的。涉及课件内容的修改，同时更新 PPTX 和 PDF，避免两个版本不一致。
- 创建 PR 时说明修改内容、原因和检查结果，由其他成员检查知识准确性、教学思路、文件完整性和代码运行情况。
- 根据反馈修改并合并。较大的问题或后续教学改进可以通过 Issue 记录，再安排负责人处理。

以上是后续多人协作的组织设想，不代表本次已经开展了多人审阅。
